# Densitometry QC — ЛЦТ 2026

Сервис автоматического контроля качества DXA/DICOM-снимков позвоночника и
бедренных костей. Решение принимает ZIP-архив с одним или несколькими
исследованиями, обрабатывает каждый DICOM и показывает результаты в веб-интерфейсе.

## Запуск одной командой

На Linux x86_64 с установленным Docker выполните:

```bash
git clone https://github.com/ermilovim/densitometry-lct-2026.git && cd densitometry-lct-2026 && ./scripts/deploy.sh
```

После успешного health check откройте:

```text
http://<IP-адрес-сервера>:8765
```

Скрипт автоматически:

- проверит Docker, свободное место и параметры запуска;
- скачает официальный checkpoint экспериментальной DXA-to-3D-модели и проверит SHA-256;
- соберёт Docker-образ с закреплёнными версиями зависимостей;
- подключит NVIDIA GPU, если он доступен Docker;
- при отсутствии GPU запустит более медленный CPU-режим;
- запустит контейнер и дождётся ответа `/api/health`;
- при неудачном обновлении восстановит предыдущий контейнер.

Подробные требования, настройки и решения типовых проблем приведены в
[`DEPLOYMENT.md`](DEPLOYMENT.md).

## Возможности

- пакетная загрузка ZIP с несколькими исследованиями;
- отдельная строка результата для каждого DICOM;
- распознавание `spine`, `left_hip`, `right_hip`;
- контроль укладки, оси позвоночника, артефактов, ротации бедра и ROI;
- просмотр DICOM, landmarks, геометрических объяснений и Grad-CAM;
- экспорт результата в CSV и XLSX;
- экспериментальная 3D-визуализация формы позвоночника;
- очередь заданий и понятный статус длительной обработки.

## Формат входа

Один ZIP-архив с DICOM-файлами. Файлы могут находиться в подпапках; имена папок
и файлов могут быть произвольными. Ограничения веб-интерфейса после распаковки:

- до 10 000 файлов;
- до 2 ГиБ суммарного размера.

Безопасный синтетический пример находится в
[`examples/example_input.zip`](examples/example_input.zip). Он не содержит
реальных снимков или метаданных пациентов.

## Формат выхода

Итоговая таблица содержит:

| Поле | Описание |
|---|---|
| `path_to_study` | путь к исследованию внутри архива |
| `study_uid` | DICOM Study Instance UID |
| `image_uid` | DICOM SOP Instance UID |
| `anatomical_region` | `spine`, `left_hip`, `right_hip` или `unknown` |
| `quality_class` | `0` — нарушений нет, `1` — требуется внимание |
| `violation_type` | найденные нарушения |
| `processing_status` | `Success` или `Failure` |
| `time_of_processing` | время обработки конкретного DICOM в секундах |

Пример: [`examples/example_output.csv`](examples/example_output.csv).

## Запуск inference без веб-интерфейса

```bash
uv sync
uv run python scripts/run_full_inference.py \
  --input examples/example_input.zip \
  --out-csv artifacts/submission.csv
```

На выходе создаётся `artifacts/submission.csv`, а подробные промежуточные
результаты записываются в `artifacts/full_inference/`.

## Состав репозитория

- `Dockerfile`, `pyproject.toml`, `uv.lock` — воспроизводимое окружение;
- `scripts/deploy.sh` — публичный запуск одной командой;
- `scripts/run_full_inference.py` — единая точка пакетного inference;
- `viewer/` — веб-интерфейс и HTTP API;
- `artifacts/` — необходимые веса и шаблоны моделей;
- `examples/` — синтетический вход, ожидаемый выход и генератор примера;
- `PIPELINE_SCHEME.md` — схема ML-пайплайна;
- `DEPLOYMENT.md` — развёртывание и диагностика.

## Модели

В репозитории находятся компактные веса, необходимые основному QC-пайплайну:

- heatmap landmark-модели;
- KNN landmark fallback;
- классификаторы укладки и артефактов позвоночника;
- шаблон определения стороны бедра.

Checkpoint DXA-to-3D не хранится в Git: `scripts/deploy.sh` скачивает его из
официального источника, проверяет SHA-256 и сохраняет в `artifacts/dxa3d/`.
Сведения о сторонней модели и лицензии приведены в
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
