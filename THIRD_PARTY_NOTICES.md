# Сторонние компоненты

## DXA-to-3D

Экспериментальная 3D-визуализация основана на опубликованной архитектуре и
checkpoint проекта [DXA-to-3D](https://github.com/EmmanuelleB985/DXA-to-3D).
Исходный проект распространяется по лицензии MIT; копия лицензии находится в
[`licenses/DXA-to-3D-LICENSE`](licenses/DXA-to-3D-LICENSE).

Checkpoint не включён в Git-репозиторий. Скрипт развёртывания скачивает его из
ссылки, опубликованной авторами проекта, и проверяет фиксированную SHA-256 сумму.

Остальные сторонние Python-зависимости перечислены с закреплёнными версиями в
`uv.lock` и устанавливаются из официальных package indexes при сборке образа.
