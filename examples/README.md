# Пример входа и выхода

`example_input.zip` содержит одно полностью синтетическое исследование из трёх
DICOM-файлов: позвоночник, правое бедро и левое бедро. В архиве нет снимков или
метаданных пациентов. Архив можно загрузить через веб-интерфейс либо обработать
командой:

```bash
uv run python scripts/run_full_inference.py \
  --input examples/example_input.zip \
  --out-csv examples/example_output.csv \
  --work-dir artifacts/example_run
```

`example_output.csv` показывает формат результата. Численные предсказания для
синтетических изображений служат только проверкой технического запуска и не
являются показателем медицинского качества модели.

Повторно создать входной архив можно командой:

```bash
uv run python examples/create_example.py
```
